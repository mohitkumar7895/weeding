# WedWithMe customer mobile

Expo app that calls the same Next.js `/api` routes as web.

```bash
cd mobile
npm install
EXPO_PUBLIC_API_URL=https://your-domain npm start
```

Android: `npm run android`  
iOS: `npm run ios`

Store accounts must be company-owned (Google Play / Apple Developer). This folder is the in-scope customer MVP client, not a second backend.
